# Запуск и развёртывание

## Локально

Нужны Node 22+ и Postgres.

```bash
npm install
createdb kubyshka_dev

# сервер
cd apps/api
DATABASE_URL="postgres://$USER@127.0.0.1:5432/kubyshka_dev" COOKIE_SECURE=false PORT=3100 npm run dev

# клиент, в другом окне
npm run dev --workspace @kubyshka/web
```

Приложение откроется на `http://127.0.0.1:5173`, запросы к `/api` проксируются на сервер. Миграции накатываются при старте сервера.

Проверить сервер целиком, включая разрешение конфликтов:

```bash
node scripts/smoke.mjs http://127.0.0.1:3100
```

## На своём VPS

Нужны Docker с плагином compose и домен, A-запись которого указывает на сервер.

```bash
git clone <репозиторий> kubyshka && cd kubyshka
cp .env.example .env
```

Заполнить `.env`:

```
DOMAIN=kubyshka.example.com
POSTGRES_PASSWORD=<openssl rand -base64 24>
SETUP_CODE=<необязательно>
```

Собрать клиент и поднять всё:

```bash
npm install
npm run build --workspace @kubyshka/web
docker compose up -d --build
```

Caddy сам получит сертификат Let's Encrypt, поэтому порты 80 и 443 должны быть свободны. Если на сервере уже работает nginx или Traefik, уберите сервис `web` из `docker-compose.yml`, пробросьте порт сервиса `api` наружу и направьте на него `/api`, а содержимое `apps/web/dist` отдайте существующим веб-сервером.

### Первый вход

Откройте домен в Safari на iPhone, нажмите «Поделиться» и «На экран Домой». Запускать приложение дальше нужно именно с иконки: без этого iOS не включит полноэкранный режим и будет агрессивнее вытеснять локальную базу.

При первом открытии приложение предложит создать семью: имя и PIN. Сразу после этого оно один раз покажет ключ восстановления. Его нужно сохранить в менеджере паролей или распечатать. Без этого ключа и без телефона, где Кубышка уже открыта, записи прочитать нельзя: в базе и в ночном дампе лежит только шифротекст.

После создания семьи регистрация закрывается навсегда. Второй человек входит по ссылке или QR из раздела «Ещё»: шесть цифр открывают вход, а ключ семьи передаётся в части ссылки после `#` и на картинке. На сервер эта часть не попадает. Вернуть сессию по имени и PIN можно, но без ключа восстановления суммы останутся нечитаемыми.

Если между развёртыванием и вашим первым открытием пройдёт заметное время, задайте `SETUP_CODE` — тогда создать семью сможет только тот, кто знает код.

### Обновление

```bash
git pull
npm install
npm run build --workspace @kubyshka/web
node scripts/publish-integrity.mjs
git add integrity.json
git commit -m "Публикует хеши сборки"
git push
docker compose up -d --build
```

`scripts/publish-integrity.mjs` пишет SHA-256 файлов из `apps/web/dist` в `integrity.json` рядом с репозиторием и в саму сборку. Клиент перед включением новой версии скачивает `https://raw.githubusercontent.com/PavelPyasecky/kubyshka/main/integrity.json` и сравнивает хеши с файлами, которые только что отдал сервер. Пока файл на GitHub не совпадает или его не удаётся скачать, открытое приложение оставляет старую версию и объясняет, что делать.

Репозиторий сейчас закрытый, поэтому анонимный запрос к `raw.githubusercontent.com` получит отказ, и обновление не включится. Токен в клиент класть нельзя. Нужно одно из двух:

- открыть репозиторий, чтобы этот файл читался без входа;
- выложить тот же `integrity.json` в публичный репозиторий или gist и собрать клиент с адресом файла: `VITE_RELEASE_MANIFEST_URL=https://raw.githubusercontent.com/<владелец>/<репозиторий>/<ветка>/integrity.json`.

Политика CSP уже разрешает только origin `https://raw.githubusercontent.com`, поэтому адрес должен быть на нём. Сначала пушится манифест, потом выкатывается та же сборка. Другой порядок или ручная правка файлов на сервере останавливает обновление.

### Резервные копии

Контейнер `backup` каждые сутки кладёт сжатый дамп в `./backups` и хранит последние четырнадцать. В дампе финансовые поля зашифрованы. Восстановление базы возвращает синхронизацию, но не читает записи без ключа семьи. Восстановление:

```bash
gunzip -c backups/kubyshka-2026-11-19.sql.gz | docker compose exec -T db psql -U kubyshka kubyshka
```

### Если что-то не работает

```bash
docker compose logs -f api      # ошибки сервера
docker compose logs -f web      # выпуск сертификата
docker compose exec db psql -U kubyshka kubyshka -c '\dt'
```

Состояние синхронизации на устройстве видно в разделе «Ещё». Кнопка «Выйти на этом устройстве» стирает локальную базу и отзывает токен, данные на сервере остаются.
