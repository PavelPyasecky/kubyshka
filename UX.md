# Кубышка — интерфейс

## 1. Принципы

1. **Два действия на операцию.** Любой элемент, который можно подставить автоматически, подставляется автоматически.
2. **Ответ раньше подтверждения.** Операция появляется в списке сразу, индикаторов загрузки в приложении нет.
3. **Цифры крупные, хром тихий.** Цветом выделяются только суммы и превышения; остальное — нейтральный серый.
4. **Поведение iOS.** Модальные листы с перетаскиванием, крупные заголовки, свайп назад, безопасные зоны, тактильный отклик.

## 2. Визуальный язык

| Параметр | Значение |
| --- | --- |
| Шрифт | Системный iOS; цифры — моноширинные начертания цифр, чтобы суммы не прыгали |
| Акцент | Глубокий зелёный |
| Фон | Светлая тема: почти белый с серыми группами. Тёмная: почти чёрный с приподнятыми карточками |
| Расход / доход | Тёмно-красный и зелёный только в числах |
| Превышение лимита | Янтарный при приближении, красный при превышении |
| Радиусы | 12 для карточек, 20 для листов, 999 для чипов категорий |
| Иконки | Один набор контурных иконок, категории различаются цветом подложки |
| Отступы | Шаг 4, боковое поле экрана 16 |
| Касания | Минимальная высота 44 |
| Анимации | 200 мс, стандартная кривая iOS; графики появляются один раз, без повторов |

## 3. Карта экранов

```
Таббар: Главная | Операции | [ + ] | Аналитика | Ещё

Главная          остаток, месяц (потрачено и отложено), рекомендации, последние
  └ Накопления   копилка, темп, прогноз, история по месяцам
Операции         список по дням, поиск, фильтры → карточка операции
[ + ]            лист ввода (поверх любого экрана)
Аналитика        период, кольцо категорий, динамика, топ трат, срезы
Ещё              счета, категории, лимиты, норма и ожидаемый доход, семья, устройства
```

## 4. Главная

Без прокрутки помещается:

1. **Остаток по всем счетам** — крупное число без карточки, прямо под заголовком месяца.
2. **Карточка месяца** — две колонки: потрачено и отложено.
3. **Рекомендации** — до двух строк, смахиваются вбок, чтобы скрыть.
4. **Последние операции** — три штуки, тап ведёт в карточку.

Ниже по прокрутке: карточки счетов и прогресс лимитов по категориям.

### Карточка месяца

```
┌──────────────────┬──────────────────┐
│ Потрачено        │ Отложено         │
│ 62 400 Br         │ 79 600 Br         │
│ ▬▬▬▬▬│▬▬         │ ▬▬▬▬▬▬▬▬         │
│ из 120 000 Br     │ норма 40 000 Br   │
├──────────────────┴──────────────────┤
│ К 30 ноября при таком темпе         │
│ отложится 43 500 Br                  │
└─────────────────────────────────────┘
```

Расход и накопление — две стороны одного месяца, поэтому они стоят рядом, а не в разных блоках: иначе экран не помещается без прокрутки и теряется связь между ними.

Левая полоса — потраченное от лимита, засечка на ней показывает, какая доля месяца прошла. Разрыв между заливкой и засечкой и есть ответ на вопрос «укладываемся ли».

Правая полоса — прогноз накоплений относительно нормы, а не текущий факт. Факт в начале месяца всегда выглядит прекрасно и к концу тает, поэтому полоса, построенная на нём, обманывала бы. Полоса зелёная, когда прогноз достигает нормы, и янтарная, когда нет.

Нижняя строка — единственное место, где названа дата конца месяца. Она отвечает ровно на вопрос «сколько получится отложить с такими темпами», и потому вынесена в отдельную строку во всю ширину.

## 5. Ввод операции

Главный экран продукта. Открывается центральной кнопкой с любого экрана, занимает лист на весь рост.

```
┌─────────────────────────────┐
│  Расход · Доход · Перевод   │  сегмент, по умолчанию «Расход»
│                             │
│         1 240 Br             │  крупное число, набирается ниже
│      Тинькофф · сегодня     │  подставлено, тап меняет
│                             │
│ [Продукты][Кофе][Такси]     │  шесть предсказанных категорий,
│ [Дом][Аптека][Другое]       │  тап = операция сохранена
│                             │
│  1 2 3 / 4 5 6 / 7 8 9      │  своя клавиатура, не системная
│  . 0 ⌫                      │
└─────────────────────────────┘
```

- Клавиатура своя: системная на iOS перекрывает пол-экрана и прячет категории.
- Тап по чипу категории сохраняет операцию, закрывает лист, даёт тактильный отклик.
- Внизу на 5 секунд появляется плашка с отменой.
- «Другое» разворачивает полный список с поиском; выбранная категория запоминается для подсказок.
- Заметка и теги — отдельный необязательный шаг через иконку, не в основном пути.

Путь: открыть, набрать сумму, тапнуть категорию. Два действия после открытия.

## 6. Операции

Список сгруппирован по дням с итогом дня в заголовке. Строка: иконка категории, название, счёт и автор мелким шрифтом, сумма справа.

Свайп по строке: удалить и дублировать. Дублирование — быстрый способ внести повторяющуюся трату до появления шаблонов.

Поиск по заметке и сумме, фильтры по счёту, категории, участнику и периоду в листе сверху.

## 7. Аналитика

Переключатель периода сверху, по умолчанию текущий месяц, смахивание влево и вправо листает месяцы.

1. Сводка: пришло, ушло, разница.
2. Кольцо расходов по категориям, под ним список с суммой, долей и изменением к прошлому месяцу.
3. Столбцы доходов и расходов за 12 месяцев.
4. Топ-10 трат периода.
5. Срезы по участникам и счетам.
6. Средний расход в день и прогноз на конец месяца.

Графики без легенд и подписей осей: подписи в списке под графиком, тап по сегменту подсвечивает строку.

## 8. Накопления

Открывается тапом по колонке «Отложено», а не из нижней панели: это экран для разбора раз в месяц, а не для ежедневного использования.

1. **В копилке** — сумма накопительных счетов, ниже прирост за месяц.
2. **Отложено в ноябре** — факт крупно, полоса прогноза к норме, под ней прогноз и процент выполнения.
3. **Сколько откладывали** — двенадцать столбцов по месяцам с пунктирной линией нормы. Текущий месяц показан прогнозом: контур вместо заливки. Под графиком — среднее за три месяца в сравнении с нормой.
4. **Переведено в копилку** — сколько из отложенного реально ушло на накопительный счёт, и кнопка перевода с уже подставленной суммой разрыва.

Разрыв между «отложено» и «переведено» — главная мысль экрана. Приложение не требует переводить деньги, чтобы засчитать накопление, но показывает, что 49 600 Br всё ещё лежат на карте и могут незаметно разойтись.

Месяц в минус рисуется столбцом вниз и подписывается «потратили больше, чем получили». Обнулять такой месяц нельзя: исчезнет единственный сигнал, ради которого экран существует.

## 9. Настройки

Счета и категории редактируются списком с перетаскиванием порядка. Лимиты — отдельный экран со списком категорий и суммой напротив каждой.

Раздел «Семья»: участники, кнопка приглашения с шестизначным кодом и таймером, список устройств с возможностью отозвать.

## 10. Первый запуск

1. Приветствие, ввод имени и PIN.
2. Выбор стартовых счетов из готовых вариантов с указанием остатка.
3. Экран-подсказка «Добавьте на домашний экран» с иллюстрацией кнопки «Поделиться» — без этого шага на iOS не будет ни полноэкранного режима, ни надёжного хранилища.
4. Сразу открывается лист ввода первой операции.

Приглашение второго участника предлагается не в начале, а после первой недели использования: до этого делить нечего.

## 11. Состояния

| Ситуация | Что видит пользователь |
| --- | --- |
| Нет сети | Ничего не меняется; в настройках отметка «синхронизировано N минут назад» |
| Синхронизация идёт | Ничего; индикаторов загрузки нет |
| Нет операций | Пустой экран с одной кнопкой «Добавить первую операцию» |
| Нет данных для аналитики | Текст о том, что графики появятся после двух недель записей |
| Лимит превышен | Красная сумма, тактильный отклик при сохранении, карточка-рекомендация на главной |
| Темп ниже нормы | Правая полоса в карточке месяца янтарная, в строке прогноза указано, сколько не хватает |
| Месяц в минус | Отложено показывается отрицательным числом, столбец в истории рисуется вниз |
| Доступна новая версия | Тонкая полоса сверху с предложением перезапустить |
